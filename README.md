# 여행경비 플래너 v2

모바일 브라우저에서 바로 사용하는 여행경비 웹앱입니다.

## 포함 기능
- 여행 설정(여행지/기간/인원/예산/통화/환율)
- 월간 달력과 날짜별 총 지출
- 달력 날짜 선택 후 지출 저장
- 지출 기록 자동 누적
- 지출 수정/삭제
- 카테고리 필터 및 정렬
- 외화 금액 원화 자동 환산
- 여행 준비 체크리스트 및 진행률
- CSV 내보내기
- 브라우저 localStorage 자동 저장
- 모바일/PWA 친화 레이아웃

## GitHub Pages 업로드
`index.html`, `styles.css`, `app.js`, `manifest.webmanifest` 네 파일을 저장소 루트에 올리면 됩니다.


## 환율 입력 방식
- 모든 통화는 `1 외화 = 몇 원(KRW)` 형식으로 통일합니다.
- 예: Google/Naver/XE에서 `1 JPY KRW`, `1 USD KRW`를 검색해 나온 숫자를 그대로 입력합니다.
- 기존 v2의 `1,000원 = 외화 몇 단위` 데이터는 최초 로드 시 자동 환산해 이어서 사용합니다.
